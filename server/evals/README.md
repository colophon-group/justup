# Model evaluation

Read [the model guide](../../docs/models.md) before changing a task profile or running a live check. `intent-heldout.json` and `company-heldout.json` record broader provider-free contracts. `luna-qualification-v1.json` fixes the bounded live case order, expectations and repeats; `luna-qualification.mjs` scores only redacted outcomes. The CLI requires the trusted queue launcher, reviewed isolation attestation and a separate one-use root grant. Local tests use fake model responses and make no provider or host calls.
