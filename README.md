# Justup

Justup is a job discovery service in development. It brings together fresh jobs from company career pages, natural-language search and transparent coverage.

The [current browser interface](prototype/README.md) has a searchable job feed, company catalogue and company requests. It uses fictional data and simulated services while the live application is built.

The accepted [backend design](docs/backend-design.md) defines search interpretation, company discovery, AI matching and Hiring Wire. The [deployment plan](docs/deployment-plan.md) places frontend delivery on Cloudflare and the application on existing Hetzner capacity. These are design targets, not a claim that the live service is deployed.

Start with the [guidebook](docs/README.md) to find the current run guide, product design, contribution workflow, release requirements and credential setup.
