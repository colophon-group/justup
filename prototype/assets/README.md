# Map shapes

`world-map.svg` is generated from Natural Earth's 1:110m country boundaries:

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- Public-domain terms: https://www.naturalearthdata.com/about/terms-of-use/

The asset contains simplified projected country paths, with a Europe crop for this sample dataset. It is loaded locally, has a reserved size to avoid layout shifts, and is decorative rather than an interactive information graphic. Active countries are colored from the sample company's current job locations; vague regions are not expanded into country claims. No legend or explanatory note appears in the interface.
