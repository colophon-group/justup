# AGENTS.md — Justup

Justup is a public job-discovery product in development. Use this file to find the guide for the work at hand.

Start at [README.md](README.md), then use the [guidebook](docs/README.md) to choose a guide. Read the [development and release guide](docs/development-process.md) before filing issues, committing, reviewing or releasing. Read the [secrets guide](docs/secrets.md) when working with credentials.

Before editing a file, read its short header when present and the nearest directory README when present. For earlier context, inspect the file's Git history and search issues for the semantic slug in its commit subjects. If you find separate work, follow the issue-filing path in the development guide; keep the current change focused.

Keep code and docs about the current state; follow the [guide rewrite rule](docs/development-process.md#keep-guides-current) when changing documentation. Do not provision a new external service or infrastructure spend without an explicitly approved resource issue, even if credentials are available.

Name branches for the work, not the contributor. Never add yourself as a commit coauthor or add agent self-credit to repository text; see the development guide.
